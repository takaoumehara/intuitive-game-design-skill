# 失敗のない、短く美しい体験を設計する

「モニュメントバレーみたいなものを作りたい」の**設計側**を扱う。技術側は `projection-as-rule.md`、美術と軽さは `../art-pipeline.md`。

**このジャンルは、ゲームというより短い展示に近いものです。** そして「難しくない」「短い」は欠点の指摘ではなく、達成された仕様です。ここを取り違えたまま作ると、**難易度を足して壊す**か、**長さを足して薄める**かのどちらかになります。

## 目次

## 1. 何を作っているのか

参照点として、モニュメントバレー（ustwo, 2014）の実寸を置いておきます。

| 項目 | 実際 |
| :--- | :--- |
| 体制 | **コア8人 × 55週**、制作費 **約85万ドル** |
| 内容量 | **10章 / 1〜2時間** |
| 売上 | 発売9ヶ月で約244万本・約586万ドル。2年で約1,438万ドル・2,610万DL |

**「小さくて美しいものを、少人数で、短期間で」ではありません。** 1万時間規模の工数を、1〜2時間の体験に集中投下しています。**密度がこの作品の正体**であり、そこを再現せずに形だけ真似ると、「きれいだけど何もない」ものになります。

設計者（Ken Wong）の言葉での位置づけは、**「長編ゲームや無限に遊ぶゲームではなく、映画を観る、あるいは美術館で午後を過ごす体験に近いもの」**。出発点は「**ゲームは難しくて時間がかかるから避ける**」という人たちでした。

## 2. 失敗を消すと、何が壊れるか

**死なない・失敗しない**と決めた瞬間、このスキルが他の章で使っている道具の大半が使えなくなります。

| 使えなくなるもの | 理由 |
| :--- | :--- |
| 難易度カーブ | 失敗しないので、難易度が体験を制御しない |
| リトライループ | 戻る場所がない |
| ニアミス・完全自己責任 | 賭けが存在しない |
| 速度による自動調整 | 急ぐ理由がない |

**だから代わりの緊張の供給源を、設計として名指しで置く必要があります。** 置かないと「ただ眺めるもの」になります。

| 供給源 | やること |
| :--- | :--- |
| **理解の段差** | 分からない状態を数十秒だけ作り、分かった瞬間に景色が変わる。緊張は難易度ではなく**保留の時間**から来る |
| **美しさの発見** | 操作した結果、想定より美しいものが現れる。プレイヤーは「自分がやった」と感じる |
| **物語の欠落** | 説明しない。誰で、なぜ、が分からないまま進む状態そのものが引力になる |
| **音の到達** | 操作が音になり、正しい手が気持ちのいい和音になる（`rhythm-and-synesthesia.md` §1.2） |

**「理解の段差」の長さが、このジャンルの難易度ダイヤルです。** 目安は**20〜60秒**。10秒以下だと段差として知覚されず、2分を超えると人は画面を閉じます。

## 3. 1画面完結

原則は**「解くために必要なものが、全部いま画面の中にある」**。

- スクロールしない。隠れた部屋がない。前の画面に戻る必要がない
- **したがって、失敗の原因が常に見えている。** 死なない設計で完全自己責任を成立させる唯一の方法がこれです
- そしてこの制約が、副産物として**全画面が絵として成立する**状態を作ります（Ken Wong は「どのスクリーンショットも壁に掛けられること」を基準にしたと述べています）

**検証は簡単です。** 各章のスクリーンショットを1枚撮り、**それだけを初見の人に見せて「次に何をすると思うか」を聞く。** 答えられないなら、その章は1画面完結していません。

## 4. アルバムとして構成する

Ken Wong は構成をアルバムに喩えています（Pink Floyd の Dark Side of the Moon を挙げ、「互いを引き立てる10〜12曲を選ぶように」）。実際、**各章はパズルもメカニクスも物語も建築様式も別**で、仕掛けは**使い捨て**です。

これは普通のゲーム設計の逆です。

| 普通のゲーム | このジャンル |
| :--- | :--- |
| メカニクスを1つ導入し、章をまたいで深める | **1章に1つ、そこでしか使わない** |
| 習熟が報酬 | **新しさが報酬** |
| 再利用で工数を回収する | **再利用しない。工数は章数に線形** |

### 使い捨ての設計ルール

- **1章 = 1つの新しい語彙。** 2つ入れると、どちらも印象に残りません
- **順序は「導入 → 変奏 → 裏切り」。** 3章で1つの弧を作り、その弧を3〜4回繰り返すと10〜12章になります
- **最後に一度だけ、既出の語彙を全部使う章を置く**。使い捨ての構成でも、終章だけは総括にすると、体験が閉じます
- **章と章の間に「何も要求しない画面」を置く。** 移動だけ、眺めるだけの30秒。密度の高い章が続くと、美しさが効かなくなります

## 5. 短さをどう引き受けるか

モニュメントバレーへの批判は「短い」「簡単すぎる」に集中しました。**これは設計が成功した結果として出る批判です。** 消す方法はなく、引き受け方だけがあります。

- **長さで殴り返さない。** 章を足すと密度が落ち、「きれいなだけ」に近づきます
- **価格と期待値を一致させる。** 「1〜2時間の作品です」と最初に言えている状態を作る。買った後に短いと知るのが、唯一の事故です
- **もう一度遊ぶ理由を、達成ではなく再訪に置く。** 全章をいつでも開けるようにし、章選択画面自体を作品にする
- **短さを弱点として補填する設計（収集要素、実績、周回）を足さない。** 足した瞬間に「短い作品」ではなく「薄い作品」になります

## 6. 予算が10分の1しかない時

**85万ドルは前提にできません。** 同じ性格の体験を、桁の違う予算で作る場合の縮小順序を書いておきます。

| 順序 | やること | なぜここから |
| :--- | :--- | :--- |
| **1** | **トリックを1つに絞る** | 章ごとに新しい仕掛けを作るのが最大の費用。「投影で繋がる」だけで10章作れるかを先に検証する |
| **2** | **章数を 10〜12 → 5〜7 に** | 密度を保ったまま縮むのはここ。1章あたりの工数は下げない |
| **3** | **音を最初に作る** | 音は工数あたりの体験密度が最も高い。美術より先に決めると、美術の判断が速くなる（`rhythm-and-synesthesia.md`） |
| **4** | **構図の使い回しを許す** | 同じ構図で仕掛けだけ変える。固定カメラの利点をここで初めて使う |
| **5** | **生成で「変奏」を作る** | 下記 §7.1。ただし「驚き」は生成できない |

**削ってはいけないのは1章あたりの密度です。** このジャンルは、章数ではなく1章の完成度で評価されます。5章の傑作は成立しますが、12章の凡作は成立しません。

## 7. さらに先へ進める方向

### 7.1 生成できる驚きと、できない驚き

**「章を自動生成すれば安く量産できる」は、半分だけ正しい。** 線はここに引けます。

| 生成できる | 生成できない |
| :--- | :--- |
| 同じ仕掛けの**変奏**（配置違い、難度違い） | **仕掛けそのものの発明** |
| 解の存在保証（`../simple/procedural-generation.md`） | 「そう来たか」という一度きりの驚き |
| 章の長さ・密度の調整 | 構図の美しさ |

したがって現実的な分業は、**手で作った章の間に、生成された変奏を挟む**形です。**手作りの章が「山」、生成が「谷」**。逆にすると、生成物の平坦さが体験の基調になって全体が沈みます。

### 7.2 身体を入力にする

視点や仕掛けの操作を、指ではなく身体（顔の傾き、手の位置）に渡すと、**静かな体験に「自分の身体でやっている」という層が乗ります**。このジャンルは要求が低速なので、カメラ入力の弱点（遅延・疲労）が最も出にくい領域でもあります。

設計は `input-layer.md`、実装は `camera-input.md`。**判定窓ではなく「状態」で読む**（今どの角度か）ほうが向いています。

### 7.3 音を先に置いて、体験を組む

MV では**操作そのものが発音**になっていました（仕掛けの位置ごとに音程が割り当てられ、素早く動かすと和音になる。メニューの構造物は4面それぞれに音があり、合わせて Cm を構成する）。

**これを先に決めてから章を作ると、順序が逆転して安くなります。** 「この和音が鳴る操作」を先に決め、それが成立する幾何を後から作る。音は美術より圧倒的に安く、しかも体験の記憶に残ります。

### 7.4 同じ画面を複数人で見る

固定カメラは、**全員が同じ絵を見ている**という珍しい性質を持ちます。1台の画面を2人で覗き、片方が視点、片方が仕掛けを操作する——**分業が自然に成立する**構成です。ここは MV が試していない領域として残っています。

## 8. 検証

このジャンルの検証は、離脱率でも正答率でもありません。

| 検証 | 合格の目安 |
| :--- | :--- |
| **静止画テスト**（§3） | 章のスクショ1枚で、初見が「次に何をするか」を答えられる |
| **保留の長さ** | 「分からない」状態が **20〜60秒**に収まる。2分を超える章があれば、そこが離脱点 |
| **手が止まる回数** | 1章あたり1回だけ止まるのが理想。0回は簡単すぎ、3回以上は詰まっている |
| **説明ゼロで進むか** | テキストを全部消して初見に渡す。進めるなら成立している |
| **音を消して遊ぶ** | つまらなくなるなら、音が正しく効いている。変わらないなら音が装飾になっている |
| **章の順序を入れ替える** | 印象が変わらないなら、アルバムとして構成できていない（§4） |

**最後の1つが、このジャンル特有で最も厳しい検証です。** 順序を変えても同じなら、それは10個の断片であって作品ではありません。
