# 素の Web Audio で音を作る

外部ライブラリなしで効果音を合成する時に読む。実装は `assets/sfx-library.js` にあるので、ここは**数値をどう動かせば狙った音になるか**を扱う。

## 目次
1. 音を作る4つの部品
2. 波形の選び方
3. エンベロープ（時間変化）
4. フィルター
5. ノイズ
6. 「らしく」するための調整
7. よくあるエラー

---

## 1. 音を作る4つの部品

ゲームの効果音は、実質この4つの組み合わせで作れる。

| 部品 | ノード | 役割 |
| :--- | :--- | :--- |
| **音源** | `OscillatorNode`（音程あり）/ `AudioBufferSourceNode`（ノイズ） | 何が鳴るか |
| **エンベロープ** | `GainNode` の時間変化 | どう始まり、どう消えるか |
| **フィルター** | `BiquadFilterNode` | 明るいか、こもっているか |
| **変調** | 別の Oscillator で他のパラメータを揺らす | 動きがあるか |

**ほとんどの効果音は音源＋エンベロープだけで成立する。** フィルターと変調は「らしさ」を足す段階のもので、最初から全部使おうとすると迷子になる。

---

## 2. 波形の選び方

| 波形 | 音の印象 | 向いている用途 |
| :--- | :--- | :--- |
| `sine` | 純粋、柔らかい、丸い | UI音、通知、低域の補強、癒し系 |
| `triangle` | やや柔らかいが芯がある | 汎用。迷ったらこれ |
| `square` | 硬い、レトロ、8bit | ジャンプ、コイン、ファミコン風 |
| `sawtooth` | 荒い、鋭い、攻撃的 | レーザー、エンジン、警告、ベース |

**8bit風にしたいなら `square` を選ぶ。** これだけでレトロに聞こえるのは、当時のハードが矩形波しか出せなかったという文化的な連想による。技術的な必然ではなく記号として効いている。

---

## 3. エンベロープ（時間変化）

音の性格の大半は、**周波数ではなくエンベロープが決めている**。同じ音程でも、立ち上がりが速いか遅いかで「打撃」と「ふわっと」に分かれる。

| パラメータ | 意味 | 短いと | 長いと |
| :--- | :--- | :--- | :--- |
| **Attack** | 無音→最大までの時間 | 硬い、打撃的（1〜5ms） | 柔らかい、ふわっと（50ms〜） |
| **Decay** | 最大→無音までの時間 | 乾いた、締まった（〜100ms） | 響く、余韻（300ms〜） |

```javascript
const SILENT = 0.0001;   // 0 は使えない（後述）
gain.gain.setValueAtTime(SILENT, t);
gain.gain.exponentialRampToValueAtTime(0.3, t + 0.005);   // Attack 5ms = 硬い
gain.gain.exponentialRampToValueAtTime(SILENT, t + 0.15); // Decay
```

**`exponentialRampToValueAtTime` を使う理由**: 人間の音量知覚は対数的なので、直線的に減衰させると「途中で急に消えた」ように聞こえる。指数減衰のほうが自然に減衰して聞こえる。逆に、周波数のスウィープも指数のほうが「音楽的に」聞こえる（オクターブが等間隔になるため）。

## 4. フィルター

| type | 効果 | 用途 |
| :--- | :--- | :--- |
| `lowpass` | 高域を削る＝こもる、遠い、重い | 爆発、水中、壁越し、遠くの音 |
| `highpass` | 低域を削る＝軽い、細い | 電話越し、小さいもの |
| `bandpass` | 特定の帯域だけ通す | 打撃音の芯、金属質 |

**`Q` は共振の鋭さ。** 上げるほど「キーン」という金属的な癖が出る。打撃音の硬さは `Q` で決まる（1前後＝鈍い、5以上＝金属的）。

**フィルターを時間変化させると「動き」が出る。** 爆発音でローパスを 1200Hz→60Hz と下げていくのは、爆発の高域成分が先に減衰して低い残響が残る、という現実の挙動を模したもの。

## 5. ノイズ

音程を持たない音（爆発、打撃、風、足音）はノイズから作る。

```javascript
function noiseBuffer(ctx, seconds) {
  const len = Math.floor(ctx.sampleRate * seconds);
  const buf = ctx.createBuffer(1, len, ctx.sampleRate);
  const data = buf.getChannelData(0);
  for (let i = 0; i < len; i++) data[i] = Math.random() * 2 - 1;
  return buf;
}
```

**ノイズ単体では「シャー」で終わる。** 必ずフィルターを通し、多くの場合は低域のサイン波を足す。爆発の迫力は、ノイズではなく**足した低域**から来ている。

継続音（風、雨）は `loop = true` にする。ノイズは周期性がないので、ループの継ぎ目が聞こえない。

## 6. 「らしく」するための調整

作った音が「安っぽい」と感じる時、原因はたいていこの3つ。

### 6.1 毎回まったく同じ音になっている
足音・打撃・タイプ音のような**反復する音**は、毎回同じだと3回目で偽物だと分かる。ピッチと長さを ±20% ほどランダムに振るだけで、耳は「別の一発」として受け取る。

```javascript
const freq = 180 + Math.random() * 120;
const dur  = 0.05 + Math.random() * 0.03;
```

これは全ての反復SEに効く、最も費用対効果の高い調整。

### 6.2 音が1層しかない
現実の音は複数の成分でできている。「打撃」なら、アタックの高域ノイズ＋胴鳴りの中域＋衝撃の低域。**2〜3層重ねるだけで急に本物らしくなる。**

### 6.3 長すぎる
効果音は思っているより短くていい。UI音は30〜60ms、効果音は80〜300ms。長い音は次の音と重なって濁り、連射すると耐えられなくなる。**「短すぎるかな」と思うくらいが適正。**

## 7. よくあるエラー

| 症状 | 原因 | 対処 |
| :--- | :--- | :--- |
| **何も鳴らない、エラーも出ない** | `AudioContext` が suspended | ユーザー操作のハンドラ内で `resume()` |
| `RangeError` / 例外 | `exponentialRampToValueAtTime` に 0 を渡した | `0.0001` を使う |
| **2回目以降鳴らない** | `Oscillator` を使い回した | 発音のたびに新規作成する |
| **だんだん重くなる** | ノードを `disconnect()` していない | `onended` で切断（`audio-engine.js` が実装済み） |
| **「バリッ」と歪む** | SEが重なってクリップ | マスターに `DynamicsCompressor` を挟む。音量を下げても直らない |
| **プツッと鳴る** | 音量を瞬時に変えた | `setTargetAtTime` / ramp で時間をかける |
| **リズムがヨレる** | `setInterval` で直接鳴らしている | 先読みスケジューラを使う |
| `decodeAudioData` が失敗 | エラーレスポンス（401等）をデコードしようとした | `res.ok` を先に確認 |
