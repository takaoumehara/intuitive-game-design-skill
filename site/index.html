Games nobody has to read instructions for.

A good door tells you whether to push or pull by its shape. When it needs a sign that says PUSH, it has already failed. This skill turns “you'll get it once I explain” into “you get it without being told” — then makes it feel good to touch and sound like something.

01What it is

“Intuitive” as something you can check

Five questions turn a vague word into a verdict. Every answer ships with its grounds, a way to verify it, a P0/P1/P2 priority and what was rejected.

  • Q1

    First-30-seconds test

    Can a first-timer make the first move with zero explanation?

  • Q2

    Affordance gap

    Name exactly where what the player perceives differs from what is real.

  • Q3

    At most four new things at once

    Respect the working-memory limit when introducing rules.

  • Q4

    Tight coupling

    Before adding a rule, can an existing variable carry the depth instead?

  • Q5

    Three-layer feedback

    Are pre, immediate and post feedback all present?

03Features

Working code for the parts everyone gets subtly wrong

Not just advice. The skill ships runnable implementations you can drop into a web game.

juice-controller.js

Coyote time & input buffer

Coyote time 100–150 ms and a 100 ms input buffer that consume both timers correctly — the fix for “the jump sometimes doesn't respond”.

audio-engine.js

A Web Audio engine

Unlock on first gesture, voice limits and a look-ahead scheduler. Diagnoses iPhone silence by checking the suspended state first.

chunk-generator.js

A level generator that stays fair

Endless chunks that provably never produce an unclearable gap.

Gets better with use

Failures become regression tests

  1. Each session appends seven lines to .claude/feedback/intuitive-game-design.md in your project.
  2. The line that matters most is Corrected: — what you had to say twice.
  3. Hand the file back. A script turns confirmed failures into eval cases, so a fix stays fixed.
Eval · honest status

A historical run on an earlier 12-case / 64-assertion set scored 97% with the skill against 66% without it, graded by an independent model. Its raw answers, model names and date were not committed, so treat it as unverified. The current suite has 21 cases / 158 assertions; re-measurement is pending.

04Install

Two lines in Claude Code

The plugin installs only the skill — not the READMEs, evals or build output. Restart, then say what you are working on.

claude code
/plugin marketplace add takaoumehara/intuitive-game-design-skill
/plugin install intuitive-game-design@intuitive-game-design

Recommended.

bash
git clone https://github.com/takaoumehara/intuitive-game-design-skill.git
ln -s "$(pwd)/intuitive-game-design-skill/skills/intuitive-game-design" \
  ~/.claude/skills/intuitive-game-design

Symlink so edits take effect immediately, or copy into <project>/.claude/skills/ to share with your team through git.

bash

05FAQ

Frequently asked questions

Do I have to choose a path myself?
No. Describe the problem in your own words. The router picks one of the ten paths and loads only what that path needs.
Is it only for web games?
The design, diagnosis and playtest paths apply to any game. The bundled implementations, sound path and tech-choice path focus on the web stack.
How reliable is the 97% figure?
It is a historical result on an earlier 12-case set, and the raw outputs were not committed, so it cannot be reproduced from the repository. The current 21-case / 158-assertion suite has not been re-run yet. evals/README.md lists what a re-measurement must commit.
Does it cost more tokens?
In the historical run, roughly 1.9× the tokens and about 80 seconds more per answer, because it reads reference files before answering. This is also to be re-measured.
Can I use it in Japanese?
Yes. The skill body is in English and the reference files are currently in Japanese. Claude reads both and answers in your language.
Does it work outside Claude?
There is a claude.ai zip and a Google Gem export under dist/. Both are currently stale; rebuild them with the scripts in the repository.
